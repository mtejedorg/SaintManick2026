## 4. Booby traps (cumulative — every executor reads this)
0. **Respawn is deferred:** a lethal hit calls `GameManager.respawn_or_game_over` via `call_deferred` (the chain used to run inside the physics flush and flip monitoring/use_collision there). Tests that kill Nick must `await get_tree().process_frame` before asserting respawn state. Area3D/CSG flips stay `set_deferred`.
1. Everything in rev. 6 §4 still applies (import/blender off, `depth_draw_never`, dormant-boss gating, pause Esc ownership, WHITE tint keeps textures, i-frames, heavy attacks free, `nick_body_v2.glb` unrigged, `.tscn` editing rule, executor reports lie by omission, Godot 4 gotchas, AudioManager no-ops, test framework disconnects SignalBus, zone names, state self-heal, `max_shield` 0 default, hurtbox groups, `KatanaHitbox` not parented).
2. **Physics layers:** player body 2, enemies 3, world 1; a body-detecting Area3D masks 2. The slice shipped for months with nothing firing — `probe_triggers.tscn` guards it.
3. **Never pause the whole tree from a tool** (black frames); freeze actors with `process_mode = DISABLED`. Never `add_child` or flip `monitoring` inside an Area3D signal — `call_deferred`.
4. **Hitboxes:** the Mixamo body faces local +Z; forward offsets go on Z, not X.
5. **Rails:** `player.current_path` is a setter (eases); top-down passes `null`; rail ends must overlap the next trigger (test).
6. **Legacy UI PNGs are full canvases** — use `ui/hud/art/`; textures load via `ResourceLoader.exists`, never `FileAccess.file_exists` (false in exports).
7. **Line endings:** `vertical_slice.tscn` is CRLF; rewriting it with a script that normalises line endings makes a 2000-line diff — preserve them.
8. `ZoneAtmosphere` duplicates the Environment at runtime; `stage_light.gd` overrides scene energy/colour in `_ready`.
9. Running two Godot instances on the project at once is fine for tests/smoke; never two `--import`s.
